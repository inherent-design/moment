# Security

Report sensitive vulnerabilities through [GitHub private vulnerability reporting](https://github.com/inherent-design/moment/security/advisories/new). Public issues are appropriate for ordinary defects without sensitive details. Include affected version/source, actual boundary, reproduction and observed impact. Never include live credentials, refresh tokens, personal stores or raw conversations.

Moment is a preview project. Use the latest qualified preview and retain migration/recovery evidence when upgrading; no long-term support window is promised. Host permissions and current user authorization remain authoritative. Local sockets and Node launch guards are not hostile-code isolation. Generated memory, retrieved guidance, model confidence and proof artifacts cannot grant themselves authority.

The [dependency procedure](docs/development/dependencies.md#automated-proposals-and-security) owns locked production/development scans, redacted findings and scoped dispositions. Missing scans are not successful results. Publication and local rollout have separate integrity, authorization and recovery checks in [releasing](docs/development/releasing.md).
