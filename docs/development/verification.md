# Verification

Qualification applies to an identified source, toolchain, artifact, environment and input scope. A successful read, model verdict, type check or fixture does not establish a broader operational claim. Retain exact commands, outputs, counterexamples and material omissions in the owning central intent. This document owns the check map and established boundaries; Git and central captures retain superseded detailed reports.

Run `mise -E security install` before scanner/workflow checks. Native checks require an installed supported Codex boundary. Live inference additionally requires a selected unexpired access session; no refresh token or primary writable authentication state is shared. See [dependencies](dependencies.md) and [releasing](releasing.md).

Store readback can be expensive because it interprets the complete retained history. Run it explicitly for a recognized current-format baseline before a relevant migration or rollout. It takes individually consistent kernel and memory snapshots; their capture times do not constitute one atomic cross-database epoch. It compares full logical fingerprints before and after constructors/readback and actual process death on the copies, then removes successful test copies. Failure retains private recovery files. It neither converts legacy formats nor verifies every raw capture's availability. A production conversion still requires its own qualified custody, preconditions, backup and recovery procedure.

Keep Node's test runner: these tests exercise Node/SQLite, subprocesses, Unix sockets and installed packages. Vite/Vitest would add a runner without improving an identified boundary. Knip follows actual package/script/test entries and documented dynamic workers. TypeScript owns strict contract examples and companion declarations. Static checks complement execution.

## Executable semantics

The proof command reports its exact frozen snapshot, declared laws, audited Lean dependencies and finite native/model comparisons. Cases cover tri-valued logic, policy precedence, immutable support edits, withdrawal, stable declaration ordering, grant boundaries, conservative policy narrowing, execution state/action tables and two-step traces. Topology adds every directed graph through three nodes, both parent modes, selected invalid/duplicate inputs, scope projection, verdict precedence and three-valued rank certificates. Admission cases cover chains through length three over four declared scope samples, six method gates, incident lifecycle/evidence, selected revision boundaries and query filters/roles. Lean proves the stated policy-envelope, execution-trace, strict-rank path, scope intersection and lifecycle properties. These results certify neither the compiler nor external effects or LLM meaning.

Numeric execution compares the two-U32 binary64 codec with native ordering over selected boundaries and generated values, including fractions, subnormals, extreme values and signed zero. It does not assume unbounded JavaScript-host Nat arithmetic. Covered source/model/toolchain/output changes refuse cold runtime startup and binding generation until rebuilt. A manifest proves coherence, not that the proof command ran. See [semantics](../reference/semantics.md).

Accounting checks compare two-word safe-integer addition/order with independent BigInt boundaries and generated values. Lean checks carry, exact addition, capacity, monotone use and retained unknown charges; finite native/model cases cover each named quantity, terminal states, measured/unknown charges and scoped two-reservation traces. Real SQLite fixtures persist a near-maximum completed charge, reject the next over-budget request without revision/outbox effects, admit the exact last unit and release an undispatched reservation. Separate observed-overrun fixtures preserve exact individual values across restart while aggregate overflow blocks dispatch. None claims those fixture quantities were measured host consumption.

Build-custody tests use an explicitly synthetic compiler to reproduce concurrent persistent and change-then-restore edits, verify frozen input bytes and preserve the previous executable/manifest on refusal. They do not qualify a compiler or a proof. Actual pinned-tool proof execution separately exercises the frozen source/model/native closure. Native graph checks include a 10,000-node chain and closing cycle, hidden-edge rejection under delegation, independent support after withdrawal and recovery after reopening the store.

## Durable effects and authority

Ordinary tests exercise real SQLite atomic state/event/receipt/outbox publication, exact retry, identity rollback, competing processes and process death before commit. Graph tests preserve independent support and historical snapshots; declaration-first ordering retains support-command order. Current grants and policies are checked at use, including revoked/expired ancestors, full namespace identity and delegated bounds. Hidden support cannot become visible authority through projection or negation.

Policy-query regressions reproduce a missing literal identity escaping as a `TypeError` and a numeric identity becoming a known negative before correction. Actual stored wide-edge and repeated-provenance fixtures exercise the node/shared-budget bounds while preserving independent observations. An explicitly instrumented in-process role array verifies that the unaffordable suffix is not decoded; it is not an admitted hostile-code sandbox test. Finite correspondence compares the complete-graph model with the actual core-selected prefix/codec over every directed graph through three nodes and named hop/budget/view combinations, alongside issuer/scope/provenance and support/cost products. Budget laws preserve exhaustion and positive observations without claiming unbounded search or native record authenticity.

Execution fixtures distinguish proposal, dispatch, cancellation request, late success, unknown outcome, reconciliation and safe replay. Actual verifier workers check bytes, measure CPU/RSS and retain durable receipts; restart can recover a receipt without another dispatch. Reservations account for resources rather than enforcing hard OS ceilings. Node launch guards are no hostile-code VM boundary. Progress requires workers/resources, clock delivery and applicable authority.

Capability comparisons cover structured schema/version/feature/isolation requirements, every seven-reason mismatch mask with incident/policy qualifications, ranking, provider publication and execution visibility/access products. Lean proves that an eligible result from the modeled compatibility pipeline requires an observed policy permit, that policy cannot erase an existing assessment, and that missing origins/incidents remain hidden. Actual kernel fixtures independently distinguish current policy denial from indeterminacy, reject effects in both cases and observe inclusive advertisement expiry while its grant remains usable. Codec tests preserve full namespaces, exact reason order, empty-chain refusal and invalid enum/text refusal. These checks do not certify advertised physical isolation or replace actual provider/schema/evidence admission.

Lease regressions reproduce epoch/monotonic rounding and a missing unknown-state deadline timer before correction. Native checks preserve fractional origins across a backward wall step, keep unknown effects uncertain at their deadline and rest after recording cancellation. Owned high-counter fixtures exercise exact persisted fencing at the safe-integer limit and refusal without revision/outbox effects. Finite model cases separately cover wall and quarter-millisecond monotonic comparisons, frame availability, lease credentials, retry/maintenance and timer/overrun selection. Their stated domains do not establish arbitrary clock accuracy or provider behavior.

Scheduler time/capacity checks compare relative calendar bounds, envelope remainders and compound request sums with the model. Actual scheduled proposal commits test two individually fitting intents: a too-small combined rule budget retains the occurrence/proposal and writes no execution or outbox effect; the exact combined budget commits both atomically. Calendar overflow refuses schedule admission without partial state, and a zero gap remains usable.

Scheduler comparisons also cover lifecycle, readiness/backpressure, event gates, coalescing order/capacity, cursor acknowledgement, visibility composition, recurrence and fair candidate choice. They exercise new-activity recovery before refreshing active executions, intervening revisions, multiple queues per incident and causal reactions between schedules. Separate ancestry tests check full reference identity, missing/foreign observations, cycles, repeated pops and the 127/128/129 boundaries. Finite causal comparisons cover every two-node edge mask with selected dependent/missing/foreign observations. None supplies missing authority or a general starvation-freedom theorem.

Storage tests cover independently decoded pooled values, exact historical identity/order, interrupted explicit conversion, forward recovery and preserved later writes. Capture tests cover additive dispositions, current authority, protected worlds/state, custody, exact bytes/metadata, interruption and matching-operation recovery. Darwin clone cases are platform-specific and skip explicitly elsewhere. Process-death checks establish neither power-loss durability nor hostile filesystem isolation. ## Session-memory candidate

Memory tests separate enrollment, observation, coverage, focus, active retention, assessment and native goal state. They cover source/profile/raw-result reconstruction, rejected-original recovery, old retries, purpose switching, late dormant-set results, current work/guidance access, UTF-8 limits and recoverable omissions. Scripted providers test transport/state boundaries rather than retention quality.

Earlier isolated low-effort Luna evaluations exercised selected actual conversations and controlled purpose changes. A 16-case corpus retained exact reconstruction and omitted originals; one flat-cache comparison lost a conditional redirect preserved in a parked working set. A later three-request compact-renderer comparison retained selected IDs with lower reported input tokens, while some notes lost numeric or conditional detail. These are single recorded comparisons, not general quality, cost or causal speed guarantees. Recoverable originals remain the source of meaning.

Actual owned TUI checks separately exercised normal hook trust, native maps, resumption and compaction. Loaded snapshots, file contents, subscription and MCP inventory are distinct observations. Configuration refresh can update definitions without trusting a changed hash. Selected ordinary canaries demonstrated intake and assessment, not universal capture. Keep actual version evidence with the run rather than imposing an exact historical CLI release gate.

## Read-packing candidate evidence

Bounded packets preserve caller detail order, writer continuation order, whole-item inclusion and explicit omitted references. Required metadata can exceed a requested limit and refuse explicitly. Read success differs from complete selection and readiness to act. Reference validation proves authorized identity/bytes, not inspection, comprehension or adoption.

Registered-source checks separate discovery, refresh, quotation anchoring, source/task/policy freshness and actual use. Historical assessments remain readable under current authority with their qualifications. A file edit becomes observable through refresh. The agent owns relevance and retrieval depth; no proof establishes freeform guidance quality or universal native compliance.

## Artifact and native evidence

Public preview `0.1.0-preview.3` qualified its exact 443,502-byte archive on macOS arm64 and Linux and verified public registry integrity/installation. Its source passed 340 macOS tests; Linux passed 334 with six Darwin skips. Its package closure contained 87 sources. These observations belong to that release, not newer candidates.

The archive check preserves manifest bytes and the packed lockfile fallback. Changed checkout locks, corrupt/missing fallback bytes and symlink substitutes refuse. SDK tests exercise negotiated legacy/modern protocols; native qualification records the actual version and admitted result. The former fixed 15-tool native MCP expectation reproduced refusal of a connected 26-tool bridge. The qualifier now derives expectations from the catalog and distinguishes protocol-only completion from authenticated parent/child work.

Reusable CI jobs define fresh Linux/macOS source/package/native checks, a fresh Linux rebuild/proof gate and pinned source/dependency security checks. Workflow validation differs from runner execution. Release receipts must identify actual completed jobs and the exact artifact. The publisher verifies and promotes that artifact without rebuilding. Installation, store compatibility and loaded native readback require separate evidence. These checks establish no Windows service support or broad model-quality guarantee.
